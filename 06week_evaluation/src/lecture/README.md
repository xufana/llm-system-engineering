# Занятие 7 — страница «Откуда вы знаете, что это работает»

Сборка: `python3 build.py` → `../../lecture7_evaluation.html` (полный документ) и `artifact.html` (без обёртки, для публикации артефактом).

- `base.css` — общие стили курса (те же, что у занятия 5).
- `extra.css` — блоки этой страницы.
- `body.html` — разметка и весь статичный текст.
- `app.js` — стенды.

Что настоящее: каппа (обычная и взвешенная) на синтетической разметке с фиксированным seed; доверительный интервал разницы средних; проверка состояния мок-среды и метрики графа (node/edge F1, эффективность, циклы, точка расхождения) — среда исполняется по трассе заново при каждом открытии; pass@k / pass^k; размер выборки для A/B (две доли, α = 0,05, мощность 0,8); бюджет вызовов. Что сценарий: разбор дерева метрик, сами трассы агента и вердикты судей по тексту и по траектории, список «что успеет измениться» в A/B, грехи.

Данные стендов живут в `app.js`: архетипы — массив `A` (метрика = `[текст, слот, объяснение]`), трассы — `TR` и задачи `TASKS` (эталонный граф, `expect(state)`, `forbidden(step)`), грехи — `S`. Новая трасса — новый элемент `TR`: среда и метрики посчитаются сами, вручную пишутся только вердикты судей и разбор.

Трассы и `data.json` для семинара: эти же четыре трассы предполагается переиспользовать в блоке D семинара как иллюстративные; настоящие 36 трасс появятся из предпосчёта семинара.
